# What is Mace Blasters?
 Mace Blasters is a Minecraft project (minigame). Originally co-created by me, Shiro Mint and vorticepen. Development is now solely led and maintained by me. If you want to know more about Mace Blasters, please feel free to check it out at the official download sites.
